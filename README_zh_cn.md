# All the Simple Challenges

中文 | **[English](README.md)**

一个为整合包 "All the Simple" 设计的挑战性 Minecraft 模组。

## 关于整合包

本模组是专为 **All the Simple** 整合包设计的附属模组，提供与整合包游戏理念相契合的挑战性内容：

- **存储压缩**：压缩方块系统解决了存储难题，玩家可以将大量圆石、钻石块等常见资源压缩成易于管理的形态。

- **资源稀缺**：食物矿石提供了通过挖矿获取食物的替代途径，为喜欢探索和洞穴探险的玩家增添了新的进度路线。

- **深度进度**：多级压缩系统创造了有意义的长期目标，鼓励玩家投入时间进行资源收集和加工。

- **核心合成**：核心物品（初级核心、ATS核心、下界合金下界之星）作为桥梁材料，可与整合包中其他模组的合成系统联动。

- **独特生物群系**：ATS森林生物群系增添了探索内容，提供独有资源以丰富整合包的世界生成。

## 内容概览

### 压缩方块系统

#### 压缩圆石
- 9级压缩圆石（1-9级）
- 每级均可合成与解构

#### 压缩钻石块
- 9级压缩钻石块（1-9级）
- 每级均可合成与解构

## 合成系统

### 压缩
高级压缩方块通过将低级方块按3x3网格排列合成。

### 解构
压缩方块可通过合成配方解构回原始组件。
